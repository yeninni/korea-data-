# 짐, 내게 와

전국 공영 물품보관함을 찾아주는 웹 서비스입니다. 공공데이터포털의 물품보관함 현황을 받아 위치, 운영시간, 요금, 크기별 남은 칸을 지도와 목록으로 보여줍니다.

- 사이트: https://yeninni.github.io/korea-data/

## 담긴 내용

- 2026년 4월 10일 기준 347곳입니다. 서울 320곳, 경기 13곳, 전남 5곳, 경남 4곳, 강원과 전북이 각 2곳, 경북 1곳입니다.
- 보관함마다 사용 가능 여부와 남은 칸, 소형과 중형, 대형 크기별 잔여, 요금, 운영시간, 큰 짐 보관 가능 여부를 표시합니다.
- 위치는 위도와 경도, 가까운 역과 정류장, 도보 시간으로 안내합니다.

## 저장소 구성

- `gh-pages` 브랜치에 실제로 게시하는 빌드 결과가 있고, `lockers.json`에 보관함 데이터가 들어 있습니다.
- `main` 브랜치에는 팀 작업 중이던 점심시간 민원 추천 프로토타입이 함께 있습니다.

## 데이터

`lockers.json`은 `source`에 출처를, `retrievedAt`에 수집 시각을, `lockers`에 보관함 목록을 담습니다. 보관함 한 건은 이름, 주소, 좌표, 잔여 칸, 크기별 잔여, 요금, 운영시간, 큰 짐 보관 여부를 가집니다.
